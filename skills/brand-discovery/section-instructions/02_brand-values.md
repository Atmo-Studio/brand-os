## What This Section Is Actually Asking

Brand values are not founder values. This distinction matters and it will blur constantly during the interview, especially in founder-led businesses where the brand's identity is deeply personal.

**Founder values** = what the founder personally believes in, how they live, what they'd sacrifice for. Real, important, and irrelevant here.

**Brand values** = what this organization stands for in the world. What it would be held accountable to by clients, partners, and the market. They must be visible in how the business operates, not just in what the founder believes.

The interview questions are designed to surface what the brand has *actually paid a price to hold*: not what the founder believes as a person. Keep this distinction active throughout. When founder values and brand values overlap (they often will), that's fine, but the test is always whether the *organization* has demonstrated it, not whether the founder lives it privately.

If the interview starts pulling into personal territory, reorient: *"That sounds like something you personally hold. Has the organization ever been tested on it? Has it cost the business something?"*

---

## Failure Modes
- Listing permission-to-play values as core: integrity, honesty, quality, respect are table stakes; any decent company in the category would claim them
- Listing aspirational values the brand doesn't yet live: these feel like core values but aren't; listing them is performative and erodes trust in the system
- Values without behavioral definitions: "excellence" and "transparency" mean nothing until the "this means / this doesn't mean" columns are filled; abstract labels alone cannot guide decisions
- Too many values: more than 5 signals that none are actually non-negotiable; press for the real ones
- A flat priority order, or no order at all: if values never conflict, they're not real values; ranking them is what makes the list honest

## Round 0: Surface Candidate Values from BRND-1

Run this before any interview questions, every time, even if the founder has an existing values doc.

Read the confirmed content from BRND-1 (Purpose, Vision & Mission). Look for language that implies a brand commitment or standard: words like "always," "never," "only," "because we believe," "what we refuse to," or direct statements of principle. Extract 2–4 candidate values you can already see operating in that content.

Present them to the founder as chat text:

> "Before we start the interview, based on what you told me about your purpose and vision, I'm already seeing a few potential core values. Let me show you what I mean:
>
> - **[Candidate value 1]** — [one sentence on where you saw it in BRND-1, e.g., "You said you built this because the existing options all cut corners on X. That suggests X matters enough to protect."]
> - **[Candidate value 2]** — [same]
> - **[Candidate value 3]** — [same if applicable]
>
> Some of these might be exactly right. Some might be the right idea but the wrong framing. Some you might reject outright. That's all fine: this is a starting point, not a verdict."

Then ask:

## Interview Rounds

**Round 1: Testing the Non-Negotiables**
*Extract: Real evidence that the brand has paid a price to hold these principles — not the founder's personal beliefs, not abstract ideals.*

*If Round 0 surfaced confirmed candidates:* Use these questions to test each one. Ask about the organization's behavior, not the founder's personal convictions. If a candidate doesn't survive the test (the founder can't name a moment the business actually held it under pressure), it may be aspirational or founder-specific, not a core brand value.

*If no candidates came from Round 0:* Use these questions to generate candidates fresh. Same standard applies: the answer must be about what the organization has done, not what the founder believes.

- Tell me about a time this organization made a decision that cost you something (a deal, a client, a hire, revenue) because of something you believed in. What was the principle you wouldn't bend on?
- Think about the best person on your team. What do they have that you'd never want to lose? If someone had exactly those skills but violated those qualities, would you keep them?
- Have you ever walked away from a client, a partnership, or an opportunity because it felt wrong? What was the line they crossed?
- Think about a hard internal decision where the easy path and the right path weren't the same. What invisible standard were you measuring against?

*Advance when: you have 3–5 values where the organization — not just the founder personally — has demonstrably held them under pressure.*

**Round 2: Defining Each Value**
*Extract: A behavioral definition for each value — what it produces in action, and what common misreadings to explicitly rule out.*

Ask the following for each value the founder named in Round 1:

- When you say "[value]," what does that actually look like on any given day? Give me an example from your own work.
- What would a misreading of this look like: someone who genuinely believed they were living this value but wasn't?
- Is there anything this value is sometimes confused with that you'd want to draw a sharp line against?

*Advance when: each value has a "this means" answer specific enough to guide a real decision, and a "this doesn't mean" answer that rules out a genuine adjacent behavior. If a founder can't name the misreading, press: "If someone used this value to justify [plausible misapplication], would that feel right to you?"*

**Round 3: Priority Order**
*Extract: A ranked order that names which value wins when values conflict. The ranking is expressed by ordering the Values table itself, top to bottom — nothing separate gets written elsewhere.*

- If [value A] and [value B] pulled in opposite directions on the same decision, which would win?
- Have you ever faced a situation where two of these values were in tension? What did you actually choose?
- If you could only protect one of these values in a crisis, which would it be? That's probably your top value.

*Advance when: the founder has given a ranked order and can defend it. A tie at the top is acceptable if genuinely held, but push once: "If you really had to choose between them, which would survive?" If they can't answer, that's valuable signal too. Note it as a question the organization hasn't fully resolved.*

**Round 4: Type Check (conditional)**
*Run only if: any value sounds like a permission-to-play value (integrity, honesty, respect, quality) or an aspirational value the founder admits the organization hasn't fully embodied yet.*

- How long has [value] been true of this organization? Has it ever been put under pressure?
- [Value] is something a lot of companies in your space would also claim. Can you name a moment it was actually expensive for you: where holding it cost you something?
- Is [value] something you have right now, or something you're working toward? There's no wrong answer, but the system needs to know the difference.

*If aspirational: don't discard it — surface it honestly. Say: "This reads more like an aspiration than a core value right now, which isn't a problem, but it belongs in a different place. Want to note it as a 'working toward' and keep the core list to what you actually live today?" Only include confirmed core values in the written page.*

## Gap Check

Run all three internally. Surface the single strongest concern.

- [ ] Permission-to-play test: would any decent company in the industry claim this value without blinking? If yes, the behavioral definition needs to be sharper, or the value should be cut.
- [ ] Authenticity test: can the founder name a real moment each value was tested? If not, it may be aspirational, not core.
- [ ] Definition test: is the "this means" answer specific enough that a new hire could actually use it to make a decision? Is the "this doesn't mean" answer a genuine exclusion: not just "we don't take this too far"?

*Values table: substitution test — could a competitor in the same category fill in this value name and behavioral definition with a straight face? If yes, the definition isn't specific enough to this brand.*
*Priority Order: expressed as the Values table's row order, not written out separately. At least one ranking should feel non-obvious. If every value feels equally ranked, the order wasn't real — return to Round 3.*
