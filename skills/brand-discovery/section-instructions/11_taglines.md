## Failure Modes
- Writing a tagline that's actually a mission statement — "Empowering teams to build better futures" is a mission statement wearing a tagline's clothes. Taglines punch; mission statements explain.
- Creating taglines in a vacuum — a tagline should be the sharpest compression of a specific messaging pillar (BRND-10). If it can't be traced to a pillar, it's clever but rootless.
- Generating taglines that could belong to any brand in the category — the test: swap your brand name for a competitor's. If the tagline still works, it's not sharp enough.
- Treating taglines as permanent — pillars are durable; taglines cycle. They're campaign-level copy with a shelf life. An "active" tagline that's been in use for three years without evaluation is probably stale.
- Polishing before selecting — founders tend to wordsmith individual taglines before choosing the right direction. Get the right *idea* first, then sharpen the *language*.

## Interview Rounds

**Round 1 · Pillar Compression**
*Extract: For each messaging pillar, the sharpest possible compression into campaign-level language.*

This round is more generative than interview-based. Work through each pillar from BRND-10:

- Look at Pillar [N]'s one-liner. If you had to say this in five words or fewer — something that would work on a billboard — what would it be?
- What's the tension this pillar captures? Can we put the tension — not the resolution — into the tagline? Tension travels further than resolution.
- Would your customer say this phrase themselves? Not about you — about their own situation. The best taglines feel like something the audience already thinks.

*Technique — the "audience-first" filter (Heath & Heath, §26):* For each tagline candidate, apply Made to Stick's SUCCESs criteria: Simple, Unexpected, Concrete, Credible, Emotional, Story. A tagline doesn't need all six, but it needs at least Simple + one other. If it's simple but predictable, it won't land. If it's unexpected but abstract, it won't stick. Push for the combination.*

*Advance when: you have at least 2–3 candidate taglines per pillar. Don't polish yet — get the right ideas before the right words.*

**Round 2 · Selection & Sharpening**
*Extract: The strongest tagline candidates, sharpened into final form and assigned to contexts.*

- From all the candidates we generated: which ones stop you? Which ones feel like they capture something true about the brand?
- For each shortlisted tagline: what context would you use this in? A website header, a campaign, a social bio, a pitch deck title?
- Let me push on each finalist. [Apply the tests below for each.]

*Technique — the four tests:*

1. **Substitution test:** Replace your brand name with a competitor's. Does the tagline still work? If yes, it's not specific enough.
2. **Audience echo test:** Would a customer say this to a friend when recommending you? If it sounds like marketing, not conversation, it's too polished.
3. **Billboard test:** Can you read it in under three seconds and remember it an hour later? If it needs context to land, it's not a tagline — it's a headline.
4. **Voice test:** Does it sound like your brand (per BRND-9)? A clever tagline that violates the brand voice is worse than a simple one that fits.

*Advance when: you have 2–5 finalist taglines, each assigned to a pillar and a context (campaign, channel, or use case). Each has survived at least three of the four tests.*

**Round 3 · Classification & Rotation (conditional)**
*Run only if: the brand has existing taglines that need to be evaluated for retention or retirement alongside new candidates.*

- For your existing taglines: are they still earning their place? Is each one still differentiated, still connected to a current pillar, still resonant with your current audience?
- If a tagline has been in use for more than a year: has the context it was written for changed? Taglines written for a launch phase may not fit a growth phase.
- For any tagline you're retiring: what's the reason? Capture it — this prevents the same tagline from being reinvented later.

## Gap Check

Run all three internally. Surface the single strongest concern.

- [ ] Pillar trace test: can each tagline be traced to a specific messaging pillar? If a tagline is clever but rootless — it doesn't connect to a pillar — it's a liability because it can't be backed by proof points.
- [ ] Substitution test: does each tagline survive the brand-swap? If it could belong to a competitor, the brand specificity isn't there.
- [ ] Voice test: does each tagline sound like this brand — per the voice description and vocabulary in BRND-9? Clever lines that violate the voice are off-brand.

## A Note on Process

Tagline generation is the most iterative page in Brand OS. Unlike the strategy pages (which are excavation — pulling out what's already true), taglines are creative output. Expect multiple rounds of generation, testing, and refinement.

The agent should generate options, not select. Present 3–5 options per pillar, apply the four tests, and let the founder choose. The founder's gut reaction to a tagline candidate — "that stops me" vs. "that's fine" — is more valuable than any framework evaluation. Trust it, but push back if a "that stops me" tagline fails the substitution test or violates the voice.
