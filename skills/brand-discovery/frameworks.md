## 1. The Golden Circle (Simon Sinek)
*Pages: BRND-1*

### Structure

```
        ┌─────────┐
        │   WHY   │  ← Purpose — start here
        ├─────────┤
        │   HOW   │  ← Process / values
        ├─────────┤
        │  WHAT   │  ← Product / service
        └─────────┘
```

### Why (Purpose)
- Why does the brand exist beyond making money?
- What belief drives the organization?
- What cause does it champion?

**Test:** "We believe that..." — if the answer is compelling and unique to this brand, it's a strong Why.

### How (Process)
- How does the brand deliver on its purpose?
- What differentiating actions or values guide the work?
- What's the unique approach?

### What (Product)
- What does the brand actually offer?
- Products, services, features
- Most brands lead with What — the strongest brands lead with Why

### Example: Apple
- **Why:** We believe in challenging the status quo and thinking differently
- **How:** We make beautifully designed, intuitive products
- **What:** We make computers, phones, and digital services

### Common Mistakes
- Starting with What instead of Why
- Making Why too generic ("we want to make the world better")
- Confusing How with features instead of values
- A Why that doesn't connect to What

*Sinek, S. (2009). Start with why. Portfolio/Penguin.*

## 2. Core Ideology + BHAG (Collins & Porras)
*Pages: BRND-1, BRND-2*

### Structure

```
┌──────────────────────────────────────┐
│            CORE IDEOLOGY             │
│                                      │
│  Core Purpose     Core Values        │
│  (the guiding     (the behavioral    │
│   star — never     principles —      │
│   fully reached)   never negotiated) │
└──────────────────────────────────────┘
                    +
┌──────────────────────────────────────┐
│                 BHAG                 │
│  Big Hairy Audacious Goal            │
│  (10–30 year stretch goal —          │
│   clear, compelling, unifying)       │
└──────────────────────────────────────┘
```

### Core Purpose
- The fundamental reason for being — not a goal, a guiding star
- "Like a horizon — you can move toward it, but never fully arrive"
- Authentic (not aspirational), enduring (doesn't change with strategy), motivating
- Passes the "5 Whys" test: keep asking why until you reach something that can't be reduced further

### BHAG (Big Hairy Audacious Goal)
- 10–30 year stretch goal — clear, vivid, and compelling
- Distinct from purpose: purpose doesn't change; BHAG is achieved (then replaced)
- Not a growth target — a transformation in the brand's relationship to its market
- Should feel slightly unreachable from where the brand stands today

**Use BHAG for Vision when:** the founder's vision statement is too operational ("reach 10K customers") or too small relative to the ambition their purpose implies.

### Examples
- **Nike purpose:** To bring inspiration and innovation to every athlete in the world
- **Nike BHAG (1960s):** Crush Adidas
- **Amazon BHAG:** Every book, ever printed, in any language, available in 60 seconds

### Common Mistakes
- Confusing BHAG with an annual goal
- Writing a purpose that reads like a mission (time-bound, audience-specific)
- Having a BHAG that no one inside the company actually believes

*Collins, J. C., & Porras, J. I. (1994). Built to last. HarperBusiness.*

## 3. Core Values Framework (Lencioni)
*Pages: BRND-2*

### Four Types of Values

```
┌─────────────────┬──────────────────────────────────────────────────┐
│ Core Values     │ Deeply held, authentic, non-negotiable           │
│                 │ The brand would be willing to be punished for     │
│                 │ holding these — even when inconvenient            │
├─────────────────┼──────────────────────────────────────────────────┤
│ Aspirational    │ Values the brand wishes it had but doesn't yet   │
│ Values          │ Danger: listing these as core = performative      │
├─────────────────┼──────────────────────────────────────────────────┤
│ Permission-to-  │ Behaviors any decent company should have          │
│ Play Values     │ (integrity, respect) — table stakes, not identity │
├─────────────────┼──────────────────────────────────────────────────┤
│ Accidental      │ Emerged from the team's personality, not intent  │
│ Values          │ Fine to have — but not the same as core values    │
└─────────────────┴──────────────────────────────────────────────────┘
```

### Extracting Core Values
- Ask: "Would we fire someone for violating this, even if they were otherwise a top performer?"
- Ask: "Would we walk away from a client or a deal over this?"
- Limit to 3–5. More than 5 = none of them are actually core.
- Each value needs a behavioral definition — what it looks like in action and what it doesn't mean

### Value Definition Format
```
Value name
↳ This means: [specific behavior or decision it produces]
↳ This doesn't mean: [common misreading or adjacent behavior to reject]
```

### Priority Order
- When values conflict, which wins? A ranked list is more honest than a flat list.
- The order reveals what the brand actually believes — press founders to rank them.

### Common Mistakes
- Listing permission-to-play values as core (integrity, honesty, teamwork)
- Listing aspirational values they don't yet live
- Values that sound identical to competitors'
- No behavioral definition — "excellence" means nothing without a "this means / this doesn't mean"

*Lencioni, P. (2012). The advantage. Jossey-Bass.*
*Collins, J. C., & Porras, J. I. (1994). Built to last. HarperBusiness.*

## 4. Jobs-to-be-Done (Christensen et al.)
*Pages: BRND-3*

### Core Premise

People don't buy products — they hire them to do a job. The job existed before the product. Understanding the job unlocks what the audience actually needs and why they switch.

### Three Job Dimensions

```
                    ┌──────────────────┐
                    │  Functional Job  │
                    │  What they're    │
                    │  literally trying│
                    │  to accomplish   │
                    └────────┬─────────┘
                             │
           ┌─────────────────┼──────────────────┐
           │                 │                  │
  ┌────────┴──────┐          │         ┌────────┴──────┐
  │ Emotional Job │          │         │  Social Job   │
  │ How they want │          │         │ How they want │
  │ to feel when  │          │         │ to be seen    │
  │ it's done     │          │         │ by others     │
  └───────────────┘          │         └───────────────┘
                             │
                   ┌─────────┴────────┐
                   │    Context       │
                   │ The situation,   │
                   │ trigger, and     │
                   │ constraints they │
                   │ operate within   │
                   └──────────────────┘
```

### Extracting the Job
- "Tell me about the last time you had this problem. What were you doing right before you went looking for a solution?"
- "When you chose [product/service], what were you hoping would be different?"
- "If this stopped working tomorrow, what would you do?"
- "What would your life look like if this job was fully done?"

### Identifying Switching Triggers
- JTBD research focuses on the moment of hiring — what pushed them to act?
- The "push" away from the old solution + the "pull" toward the new one
- Anxieties that almost stopped the switch
- Habits that needed breaking

### Common Mistakes
- Defining the job too narrowly (feature-level) or too broadly (universal human need)
- Ignoring the social job — often the most powerful driver
- Describing demographics instead of a job ("millennial professionals" is not a job)
- Confusing the job with the solution

*Christensen, C. M., Hall, T., Dillon, K., & Duncan, D. S. (2016). Competing against luck. HarperBusiness.*

## 5. Positioning Map (Perceptual Map)
*Pages: BRND-4*

### How to Build

**Step 1: Choose 2 strategic axes** — dimensions that matter to the audience AND where competitors differ:
- Price ↔ Premium
- Traditional ↔ Innovative
- Simple ↔ Complex
- Mass market ↔ Niche
- Functional ↔ Emotional
- Serious ↔ Playful

**Step 2:** Plot each competitor based on market perception — not self-image.

**Step 3:** Find white space — quadrants with few or no competitors.

**Step 4:** Validate the white space:
- Is there demand here? (empty ≠ desirable)
- Can this brand credibly claim it?
- Is it defensible long-term?

### Example: Coffee Market

```
              Premium
                │
     Artisan    │   Luxury
   (Blue Bottle)│  (Nespresso)
                │
  Functional────┼────Experiential
                │
     Budget     │   Social
    (Folgers)   │  (Starbucks)
                │
             Affordable
```

### Tips
- Validate axis selection with real audience data — don't assume what matters
- Update annually — perception shifts
- Run multiple maps with different axis pairs to find the most useful frame

*Ries, A., & Trout, J. (1981). Positioning: The battle for your mind. McGraw-Hill.*

## 6. Blue Ocean / Value Curve (Kim & Mauborgne)
*Pages: BRND-4*

### Core Premise

Red ocean = competing in existing market space. Blue ocean = creating uncontested space by questioning what the industry assumes must be offered.

### The ERRC Grid

```
┌─────────────┬──────────────────────────────────────────┐
│ ELIMINATE   │ Which factors the industry competes on   │
│             │ should be eliminated entirely?           │
├─────────────┼──────────────────────────────────────────┤
│ REDUCE      │ Which factors should be reduced well     │
│             │ below the industry standard?             │
├─────────────┼──────────────────────────────────────────┤
│ RAISE       │ Which factors should be raised well      │
│             │ above the industry standard?             │
├─────────────┼──────────────────────────────────────────┤
│ CREATE      │ Which factors should be created that the │
│             │ industry has never offered?              │
└─────────────┴──────────────────────────────────────────┘
```

### Value Curve
Plot competing factors on the X-axis (e.g., price, speed, depth, support, prestige). Plot how much each brand invests in each factor on the Y-axis. The curve reveals where the brand is identical to competitors (bad) vs. distinct (good).

**Signal:** A distinctive value curve has a different shape from competitors — it zigs where others zag.

### Common Mistakes
- Only Raising things — true blue ocean moves require Eliminating or Reducing too
- Creating factors no audience actually wants
- Using the framework to describe the present instead of design the future

*Kim, W. C., & Mauborgne, R. (2005). Blue ocean strategy. Harvard Business Review Press.*

## 7. Competitive Differentiation Matrix
*Pages: BRND-4*

### Template

| Dimension | This Brand | Competitor A | Competitor B | Competitor C |
|---|---|---|---|---|
| Price point | | | | |
| Core value proposition | | | | |
| Primary audience | | | | |
| Visual style | | | | |
| Tone of voice | | | | |
| Key differentiator | | | | |
| Biggest weakness | | | | |

### Using the Matrix
1. Fill in honestly — not aspirationally
2. Identify parity dimensions (same as everyone — must-haves, not differentiators)
3. Identify genuine differences (potential differentiators)
4. Rank differentiators by: relevance to audience × difficulty for competitors to copy
5. Lead with the top 1–2 true differentiators

## 8. Obviously Awesome Positioning (April Dunford)
*Pages: BRND-5*

### Core Premise

Positioning is not a tagline. It's the context you set that makes your value obvious. Bad positioning makes you compete on ground where you're weak. Good positioning makes your strengths the only thing that matters.

### The Five Components

```
┌─────────────────────────────────────────────────────────┐
│  1. COMPETITIVE ALTERNATIVES                            │
│     What would customers do if you didn't exist?        │
│     (Include: do nothing, spreadsheet, competitor X)    │
├─────────────────────────────────────────────────────────┤
│  2. UNIQUE ATTRIBUTES                                   │
│     What do you have that alternatives don't?           │
│     (Features, approaches, assets, team, data)          │
├─────────────────────────────────────────────────────────┤
│  3. VALUE (not features)                               │
│     What does each attribute make possible?             │
│     Shift: attribute → capability → customer value      │
├─────────────────────────────────────────────────────────┤
│  4. TARGET CUSTOMER                                     │
│     Who values this most? Where does this resonate      │
│     with enough force to drive a decision?              │
├─────────────────────────────────────────────────────────┤
│  5. MARKET CATEGORY                                     │
│     What frame of reference sets you up to win?         │
│     The category determines what you're compared to.    │
└─────────────────────────────────────────────────────────┘
```

### Attribute → Value Translation
| Unique Attribute | What it makes possible |
|---|---|
| [Feature or capability] | [Customer outcome — what they can do, feel, or avoid] |

### Market Category Framing
Choosing a category is a strategic act — it determines the comparison set.
- "CRM" → compared to Salesforce. "Revenue intelligence platform" → compared to guessing.
- Ask: "What category frame makes our strengths the obvious choice?"

### Quality Test
If a competitor's name could replace the brand name and the positioning still holds → it's not positioned, it's generic.

*Dunford, A. (2019). Obviously awesome. Ambient Press.*

## 9. Positioning Statement (Geoffrey Moore)
*Pages: BRND-5*

### Formula

```
For [TARGET AUDIENCE] who [NEED OR WANT],
[BRAND] is the [MARKET CATEGORY]
that [KEY BENEFIT / UNIQUE VALUE].
Unlike [PRIMARY ALTERNATIVE],
[BRAND] [PRIMARY DIFFERENTIATION].
```

### Components

**Target Audience:** Behavioral segment, not demographic
- Weak: "small businesses"
- Strong: "early-stage founders who are doing their own marketing"

**Need/Want:** The job-to-be-done — emotional or functional
- Weak: "need better software"
- Strong: "want to look credible without hiring a full agency"

**Market Category:** The frame that sets expectations (see Dunford §8 for framing strategy)

**Key Benefit:** The single most important differentiator — ownable, relevant, believable

**Primary Alternative:** Be honest — what do they actually use instead?

**Primary Differentiation:** What the brand does differently that produces the key benefit

### Example: Volvo
For safety-conscious families who want peace of mind, Volvo is the car manufacturer that delivers the safest driving experience. Unlike other premium automakers, Volvo makes safety the organizing principle of every design decision.

*Moore, G. A. (1991). Crossing the chasm. HarperBusiness.*

## 10. Brand Pyramid (Keller)
*Pages: BRND-5*

### Structure

```
              /\
             /  \
            / ES-\         BRAND ESSENCE
           / SENCE \       (2–3 words)
          /──────────\
         /  EMOTIONAL \    How it makes you feel
        /   BENEFIT    \
       /────────────────\
      /  FUNCTIONAL      \  What it does for you
     /   BENEFIT          \
    /────────────────────────\
   /  ATTRIBUTES              \  Features, facts, proof
  /──────────────────────────────\
```

### Levels

**Attributes (base):** Tangible features and facts
- Product specs, processes, certifications

**Functional Benefits:** What the attributes do for the user
- Time saved, problems solved, tasks simplified

**Emotional Benefits:** How the functional benefits make you feel
- Confidence, peace of mind, belonging, pride

**Brand Essence (peak):** The brand distilled to 2–3 words
- Must be ownable, memorable, and emotionally resonant
- Nike: "Authentic Athletic Performance" / Disney: "Magical Entertainment"

*Keller, K. L. (2013). Strategic brand management. Pearson.*

## 11. Dimensions of Brand Personality (Jennifer Aaker)
*Pages: BRND-6*

### Five Dimensions

```
┌──────────────────┬────────────────────────────────────────────┐
│ SINCERITY        │ Down-to-earth, honest, wholesome, cheerful │
│                  │ Brands: Hallmark, Dove, Patagonia           │
├──────────────────┼────────────────────────────────────────────┤
│ EXCITEMENT       │ Daring, spirited, imaginative, up-to-date  │
│                  │ Brands: Red Bull, Nike, Tesla               │
├──────────────────┼────────────────────────────────────────────┤
│ COMPETENCE       │ Reliable, intelligent, successful           │
│                  │ Brands: IBM, The Economist, Amex            │
├──────────────────┼────────────────────────────────────────────┤
│ SOPHISTICATION   │ Upper class, charming, refined              │
│                  │ Brands: Chanel, Rolex, Tiffany              │
├──────────────────┼────────────────────────────────────────────┤
│ RUGGEDNESS       │ Outdoorsy, tough, rugged                    │
│                  │ Brands: Jeep, Timberland, Carhartt          │
└──────────────────┴────────────────────────────────────────────┘
```

### Personality Spectrum (interview tool)
Map the brand across trait axes. Mark where it lives — and where it must never go.

```
Casual           ←───────────────────→   Formal
Earnest          ←───────────────────→   Irreverent
Grounded         ←───────────────────→   Visionary
Quiet confidence ←───────────────────→   Bold & declarative
Approachable     ←───────────────────→   Expert authority
Warm             ←───────────────────→   Cool / aspirational
```

### Using the Dimensions
- The five dimensions are orientation — use them to identify which dimension(s) the brand primarily inhabits
- The spectrum is the actionable output — maps the brand's range within those dimensions
- A brand can span multiple dimensions but should lead with one
- The spectrum also defines the "never go here" territory — equally important

### Common Mistakes
- Picking dimensions aspirationally rather than authentically
- Spreading across all five (no personality = no personality)
- Treating the dimension as the output — the spectrum mapping is the deliverable

*Aaker, J. L. (1997). Dimensions of brand personality. Journal of Marketing Research, 34(3), 347–356.*

## 12. StoryBrand / SB7 (Donald Miller)
*Pages: BRND-8*

### Core Premise

The brand is not the hero. The customer is the hero. The brand is the guide. Every piece of communication should tell the customer's story, not the brand's story. When brands make themselves the hero, they lose the customer.

### The 7-Part Structure

```
1. CHARACTER       The hero — who the customer is and what they want
        ↓
2. PROBLEM         External (the tangible problem)
                   Internal (how it makes them feel)
                   Philosophical (why it's wrong that this exists)
        ↓
3. GUIDE (us)      Empathy (we understand your problem)
                   Authority (we've helped others like you)
        ↓
4. THE PLAN        A clear, simple 3-step path forward
        ↓
5. CALL TO ACTION  Direct CTA ("Buy now") + Transitional CTA ("Learn more")
        ↓
6. SUCCESS         What their life looks like after
        ↓
7. FAILURE         What's at stake if they don't act
```

### Three Problem Levels
Every strong brand story names all three:
- **External:** The concrete obstacle ("I can't find reliable data")
- **Internal:** The emotional consequence ("I feel incompetent in front of my team")
- **Philosophical:** The injustice ("No one should have to operate blind")

### Guide Credentials
The guide establishes authority without becoming the hero:
- Empathy first: show you understand the problem
- Then authority: show you've solved it before

### Common Mistakes
- Making the brand the hero (most common)
- Skipping the internal problem — it's usually the real reason people buy
- No clear failure state — without stakes, there's no urgency
- A plan with more than 3 steps — simplicity is the point

*Miller, D. (2017). Building a StoryBrand. HarperCollins Leadership.*

## 13. Four Dimensions of Tone of Voice (Nielsen Norman Group)
*Pages: BRND-9*

### The Four Axes

```
Funny          ←───────────────────→   Serious
Formal         ←───────────────────→   Casual
Respectful     ←───────────────────→   Irreverent
Enthusiastic   ←───────────────────→   Matter-of-fact
```

### How to Use

**Voice** is fixed — who the brand is across all contexts. It doesn't change.

**Tone** is contextual — how the brand adapts its expression to the situation without losing character.

```
                    VOICE (constant)
                         │
         ┌───────────────┼───────────────┐
         │               │               │
    Crisis/              │         Celebration/
    friction        Neutral          milestone
    context         content          content
         │               │               │
    Tone shifts     Tone stays      Tone shifts
    serious,        centered        more warm,
    empathetic                      enthusiastic
```

### Tone Mapping by Context

| Context | Tone shift | Example |
|---|---|---|
| Error / failure | More serious, empathetic | Never flip, never minimize |
| Onboarding | More warm, instructional | Reassure, don't overwhelm |
| Success / milestone | More celebratory | Match the moment |
| Neutral / informational | Centered voice | Let the voice speak for itself |

### Common Mistakes
- Confusing voice (identity) with tone (context) — they're not the same
- Having only one tone across all contexts (robotic) or infinite tones (no character)
- Writing tone guidelines without examples — abstract descriptions don't transfer

*Nielsen Norman Group. (2016). The four dimensions of tone of voice. nngroup.com.*

## 14. Messaging Pillars (Bloomstein)
*Pages: BRND-10*

### Core Premise

Messaging pillars are the 3–5 core claims a brand repeats consistently across every channel. They're not taglines. They're the strategic messages that, together, make the full case for why the brand is the right choice.

### Pillar Structure

```
┌─────────────────────────────────────────────────────┐
│  PILLAR HEADLINE                                    │
│  The claim in its clearest, most portable form      │
├─────────────────────────────────────────────────────┤
│  PROOF POINTS                                       │
│  2–3 specific, provable facts or examples           │
│  that back the claim                                │
├─────────────────────────────────────────────────────┤
│  CHANNEL EXPRESSIONS                                │
│  How this pillar shows up on homepage / sales deck  │
│  / social / email — same claim, different register  │
└─────────────────────────────────────────────────────┘
```

### Three Tests for a Strong Pillar
1. **Differentiated** — does a competitor already own this claim? If yes, it's not a pillar, it's table stakes.
2. **Provable** — can you point to specific evidence? Vague claims = no pillar.
3. **Connected** — does it trace back to the positioning? Pillars should be expressions of the positioning, not random claims.

### Pillar vs. Tagline
- Pillar: durable, structural, used internally to guide content decisions
- Tagline: campaign-level compression for external use — cycles more frequently

### Common Mistakes
- More than 5 pillars — each additional pillar dilutes focus
- Pillars that all sound the same (slight rephrasing of one claim)
- Proof points that are vague ("we've helped hundreds of companies")
- No channel expressions — pillars without application don't transfer

*Bloomstein, M. (2012). Content strategy at work. Morgan Kaufmann.*
