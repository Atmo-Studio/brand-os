# MEMORY.md

What this workspace remembers, and where. Read at the start of every session. Keep it under 2,000
characters: it loads every time, so detail belongs in the files it points to.

## Where facts go

| Kind of fact | Home |
|---|---|
| The brand: purpose, audience, positioning, voice | The brand knowledge base |
| How to work on a project | That project's instructions |
| What happened in a session, and what comes next | `memory/sessions/` |
| Anything else confirmed and durable | A line under Facts below |

Write a confirmed fact to its home when you learn it. A session log records what happened, not what
is true.

## Confirmed and inferred

A fact the user stated is confirmed. A fact you worked out is inferred: write it under Facts marked
`(inferred)` until the user confirms it. When two facts conflict, the newer confirmed one wins.
Replace the old line rather than adding one beside it.
