# Session Handover Prompt

Paste this into any chat that's running long.

---

This session is getting long. Do two things:

1. Write a session log to `memory/sessions/YYYY-MM-DD_[short-topic].md` using the session-handover skill's log template (or your workspace's own session log template, if one is defined). Include a `## Next Session` section. Do not create any other file.

2. Print the ready-to-paste copy-paste block directly in chat — the same block from `## Next Session`. The block should name the project, list up to 3 files to read first (with what to check in each), and state the exact first task.

Session log covers:
- What we were working on — full context of the project or task
- Decisions locked in — frame as "don't re-litigate unless I raise them"
- Critical context a fresh Claude would miss
- Current state — what's done, what isn't
- Open questions — anything unresolved
